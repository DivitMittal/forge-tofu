# PROJECT KNOWLEDGE BASE

**Generated:** 2026-04-02 IST | **Updated:** 2026-11-20 IST | **Branch:** main

## OVERVIEW
forge-tofu is an OpenTofu + Terragrunt project (formerly forge-terraform, renamed 2026-08-14) that declaratively manages DivitMittal's repositories across GitHub, GitLab, Codeberg, gitea.com and SourceHut, plus GitHub Actions environments (secrets/variables) on the GitHub unit. Qezta's units were handed over to Qezta/infra and no longer live here. A Nix flake provides the devshell, formatters, pre-commit hooks, Terranix JSON generation and CI generation. Non-GitHub units are empty scaffolds (no repos yet). SourceHut has no branch-protection support. Codeberg and gitea.com are both Gitea instances sharing `modules/repositories-gitea` and `modules/branch-protection-gitea`, differing only in `base_url` and token.

## TOKENS
- **GitHub**: `GITHUB_TOKEN_DIVITMITTAL` → `GITHUB_TOKEN` → `gh auth token`. Needs `repo` + `admin:org`.
- **GitLab / Codeberg / gitea.com / SourceHut**: decrypted from `infra-nixCfg-secrets/secrets/forge/tofu/{gitlab,codeberg,gitea,sourcehut}.age`; override with `GITLAB_TOKEN_DIVITMITTAL`, `CODEBERG_TOKEN_DIVITMITTAL`, `GITEA_TOKEN_DIVITMITTAL`, `SOURCEHUT_TOKEN_DIVITMITTAL`.
- **GitHub state passphrase**: `forge/tofu/github-state-passphrase.age`.
- Secrets repo defaults to `../../Cfgs/infra-nixCfg-secrets` (from the main checkout), identity `~/.ssh/agenix/id_ed25519`; override with `FORGE_TOFU_SECRETS_REPO` / `FORGE_TOFU_AGE_IDENTITY`.
- `FORGE_TOFU_PLACEHOLDER_SECRETS=1` renders offline with placeholders; a precondition blocks them from reaching GitHub.
- `terragrunt validate` works without credentials; plan/apply need real tokens.

## CONVENTIONS
- `terranix/orgs/<Org>[-<Forge>].nix` is canonical — compiled by Terragrunt's `generate "locals"` block.
- Forks are intentionally unmanaged.
- `prevent_destroy = true` on every repository resource.
- Non-GitHub units override `generate "versions"`/`"provider"`; their `include "root"` needs `merge_strategy = "deep"`.
- `sourcehut_repository` has no owner attribute; `owner` is only used to compute `repo_urls`.
- GitHub unit state + plans are encrypted (enforced). `FORGE_TOFU_ALLOW_PLAINTEXT_STATE_MIGRATION=true` only for one-time plaintext migration.

## ANTI-PATTERNS (THIS PROJECT)
- Do not edit `.github/workflows/*.yml` or `.pre-commit-config.yaml` by hand (generated).
- Do not edit `orgs/*/locals.tf.json` or `orgs/*/terraform.tfstate` by hand.
- Do not remove `prevent_destroy` from repo resources.
- Do not run `tofu` directly — use `terragrunt` from inside an org directory.
- Do not use `terragrunt run-all` (deprecated) — use `terragrunt run --all`.
- Do not add a `generate "versions"`/`"provider"` override without `merge_strategy = "deep"`.

## COMMANDS
```bash
nix develop                 # tofu, terragrunt, agenix, gh, glab, tea, hut, nixd, alejandra
cd orgs/DivitMittal         # or orgs/DivitMittal-<Forge>
terragrunt plan && terragrunt apply
terragrunt run --all plan
nix fmt
nix flake check             # pre-commit hooks + github-state-encryption check
nix build .#divitmittal-locals --print-out-paths | xargs cat | jq
```
Workflows re-render on every commit via the `render-actions` pre-commit hook (no `nix run` app).

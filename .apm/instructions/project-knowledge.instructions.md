# PROJECT KNOWLEDGE BASE

**Generated:** 2026-04-02 IST | **Branch:** main

## OVERVIEW
Terraform + Terragrunt project that declaratively manages multiple GitHub organisations (DivitMittal, Qezta) with the GitHub provider, plus a Nix flake for tooling and CI generation. Terragrunt DRYs up the backend configuration and provider generation across orgs.

## STRUCTURE
```
./
├── root.hcl                     # root: remote_state (local backend) + generate "versions"
├── orgs/
│   ├── DivitMittal/             # Terragrunt unit for github.com/DivitMittal
│   │   ├── terragrunt.hcl       # include root + generate "provider"/"locals" + inputs (token)
│   │   ├── main.tf              # import blocks + module calls
│   │   ├── variables.tf         # github_token variable
│   │   ├── outputs.tf
│   │   └── terraform.tfstate    # local state (do not edit manually)
│   └── Qezta/                   # Terragrunt unit for github.com/Qezta
├── terranix/
│   └── orgs/
│       ├── DivitMittal.nix      # canonical repos map for DivitMittal (Nix → JSON)

│   ├── repositories/            # github_repository resources + validation

```

## TOKENS
- **DivitMittal**: `GITHUB_TOKEN_DIVITMITTAL` env var (falls back to `GITHUB_TOKEN`)
- **Qezta**: `GITHUB_TOKEN_QEZTA` env var (falls back to `GITHUB_TOKEN`)
- Tokens must have `repo` + `admin:org` scopes.

## CONVENTIONS
- For each org, `terranix/orgs/<Org>.nix` is the canonical source — compiled to `locals.tf.json` by Terragrunt's `generate "locals"` block.
- Fork repositories are intentionally unmanaged; omit forks from `locals.repos`.
- `prevent_destroy = true` guards every repository resource.
- Workflows in `.github/workflows/` are generated from `flake/actions/`.

## ANTI-PATTERNS (THIS PROJECT)
- Do not edit `.github/workflows/*.yml` by hand (generated).
- Do not modify `.pre-commit-config.yaml` manually (generated).
- Do not edit `orgs/*/locals.tf.json` by hand — build artefacts of `terranix/orgs/*.nix`.
- Do not remove `prevent_destroy` from repo resources.
- Do not run `terraform` directly — always use `terragrunt` from inside an org directory.
- Do not use `terragrunt run-all` (deprecated) — use `terragrunt run --all` instead.
- Do not edit `orgs/*/terraform.tfstate` manually.

## COMMANDS
```bash
nix develop

cd orgs/DivitMittal   # or orgs/Qezta
terragrunt init
terragrunt plan
terragrunt apply

terragrunt run --all plan
nix fmt
nix flake check
nix run .#render-workflows
```
